One chilling sentence: a baby monitor that has started narrating its owner three seconds before he acts. The program writes the line to `/output/entry.txt` for make.fun's [One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488) bounty — a single sentence of horror under 200 characters, judged head-to-head on how frightening, vivid, and original it is.

> My daughter's baby monitor has started narrating what I'm doing, three seconds before I do it.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (runs TypeScript directly). Deterministic, no network, no dependencies — it writes exactly one line, 94 characters, to `/output/entry.txt`.
